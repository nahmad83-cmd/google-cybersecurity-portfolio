# Security Risk Assessment

## Objective

Recommend network-hardening measures for a fictional organization after reviewing identified security weaknesses.

## Recommended Measures

### Multi-Factor Authentication (MFA)

MFA adds an additional identity-verification layer beyond passwords. This reduces the likelihood that compromised credentials alone can be used for unauthorized access.

### Strong Password Policies

Password policies should establish requirements such as minimum length, acceptable character types, restrictions on password sharing and reuse, and account lockout after repeated failed authentication attempts.

### Firewall Configuration and Maintenance

Firewall rules should be reviewed and updated regularly so that suspicious or unauthorized traffic can be filtered effectively. Firewall maintenance should also reflect current network policies and lessons learned from security events.

## Security Rationale

Together, these measures strengthen identity protection, reduce exposure to brute-force and credential-based attacks, and improve control over network traffic. The activity highlighted the importance of layered security rather than relying on a single defensive control.

## Skills Demonstrated

Security hardening, authentication controls, password security, firewall management, defense in depth, and risk-based recommendations.
