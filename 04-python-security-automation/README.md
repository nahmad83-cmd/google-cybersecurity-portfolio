# Python Security Automation

This project automates maintenance of an IP allow list. The workflow reads authorized IP addresses from a text file, converts the data to a list, removes addresses that are no longer authorized, converts the revised list back to text, and writes the result to the original file.

- [Python script](update_allow_list.py)
- [Project documentation](algorithm-for-file-updates.md)

**Concepts demonstrated:** file handling, functions, loops, conditional logic, list/string conversion, and access-control automation.
