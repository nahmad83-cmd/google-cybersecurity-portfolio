# Google Cybersecurity Portfolio

Hands-on cybersecurity portfolio developed during the **Google Cybersecurity Professional Certificate**. This repository documents practical work in security auditing, risk assessment, network traffic analysis, Linux permissions, SQL investigations, Python security automation, SOC alert triage, incident response, malware analysis, access control, and the NIST Cybersecurity Framework.

> **Portfolio note:** These projects use fictional training scenarios and lab data. They do not represent real client environments or production incidents. The material here presents my completed analyses and project documentation in a GitHub-friendly format rather than reproducing course templates.
