# Controls and Compliance Assessment

## Objective

Assess the security controls and compliance practices of the fictional organization **Botium Toys** and identify areas where security posture could be improved.

## Controls Reviewed

The assessment considered controls including least privilege, disaster recovery, password policies, separation of duties, firewall protection, intrusion detection, backups, antivirus, encryption, password management, physical locks, CCTV, and fire detection/prevention.

## Compliance Areas Reviewed

The activity examined security practices associated with:

- **PCI DSS** — protecting payment-card information, using secure processing environments, encryption, and secure password management.
- **GDPR** — protecting EU customer data, breach-notification planning, data classification, and privacy procedures.
- **SOC** — user-access policies, confidentiality of sensitive information, data integrity, and availability to authorized users.

## Security Perspective

The exercise reinforced that a security audit is not limited to technical controls. Effective security also depends on policies, physical safeguards, access management, data protection, disaster recovery, and compliance processes working together.

## Skills Demonstrated

Security auditing, control assessment, compliance awareness, access control, data protection, and security recommendations.
